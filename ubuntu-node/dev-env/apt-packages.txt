# apt-packages.txt — the system layer for any zen node (dev box, orchestrator, PXE worker).
#
# Division of labour (see mise.toml and mise.aarch64.toml in this directory):
#   mise owns user-space toolchains and CLIs   -> see mise.toml (arch-neutral)
#   apt  owns system libraries and dev headers -> this file
# So CLIs that mise already provides (gh, jq, ripgrep, fd, fzf, zoxide, just, delta, ...)
# are deliberately ABSENT here even though the outgoing box had them apt-installed.
#
# Derived from a real diff: `apt-mark showmanual` on the outgoing box (183) minus the new
# box (54) = 164 differing. That raw list is NOT what you want to install — see EXCLUDED.
#
#   sudo apt update && sudo apt install -y $(sed 's/#.*//' apt-packages.txt | grep -vE '^\s*$')
