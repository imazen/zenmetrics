# nn-opt2 — CPU host-path wins on the newer models (i265, 2026-10-15)

Lane `nn-opt2` off `nn-lpips-vgg@origin` (`61ccaed6`). Same method as
`nn_opt_2026-10-15.md`: `examples/nn_bench.rs`, rten engine,
`RTEN_NUM_THREADS=16` unless noted, `compute`/`warm` medians, interleaved
A/B in two rounds. The original 13-column upstream-parity check passed
(worst 5.65e-5 JND versus the 1e-3 gate), as did
`warm_reference_equals_cold`. Those tolerance checks alone do not establish
old-versus-new bit identity; the review measurements below check full-precision
scores separately.

Phase instrumentation (eprintln timers on a throwaway snapshot build)
measured the host share at 16T before any change:

| model@size | trunk runs | host work measured |
|---|---|---|
| ckdn@2048 | qse+dte+tail ~29ms | **dist prep ~30ms** (AA bicubic + planar), ref prep ~16ms |
| arniqa@256 | 10 sequential embeds ~32ms each | prep ~3.7ms |
| afine@1024 | pair ~972ms | head ~32ms, preps ~20ms, 2×~13MB input clones |
| liqe@256 | 1×emb ~31ms | head ~1.7ms, prep ~0.1ms — nothing owned |
| maniqa@256 | run ~600ms | prep ~0.7ms — nothing owned |
| dreamsim@1024 | 2 concurrent runs | pil_u8 bicubic ~7ms |

## Commits

`resize.rs` (f32 AA bicubic, PIL fixed-point bicubic/bilinear, cv2
INTER_CUBIC, nearest, center_crop) and `rgb8_to_planar_*` write every
output element independently → `par_each_mut` over `(channel, row)`
items, exact same per-element arithmetic (bit-identical), `threads_for`

### `c550bd94` — afine: hoist pixel stats, drop input clones, parallel head

`pix_stats`/`pix_cov` computed before `run_pair_aux` consumes `rn`/`dn`
(they only need the normalized input) — the two ~3·nh·nw f32 clones per
pair (~50MB at 2048) and the per-eval `dn` clone on the warm path are
gone. Tap stats/covariances flattened to `(tap, channel)` `par_map`
items (index order preserved); `pix_*` 3-way; CLIP normalize per
channel.

## Measured, not implemented

  a per-tap split can't balance. Under the 3% bar (carried from the
  nn-opt review round).
- **liqe**: prep 0.08ms, head 1.7ms of ~57ms — the 15×-tower fix is
  already on the PR; nothing owned left.
- **maniqa**: prep 0.7ms of ~500ms+ per `evaluate_image` — trunk-bound.
- **NR concurrent r+d eval**: `PairedNoReference::evaluate` scores both
  images through `evaluate_image(&mut self, …)` — the `&mut` borrow
  serializes them inside the adapter; fixing it is an
  abstractions-API change, out of this lane's scope.

## Round 10: measured score identity

The shared benchmark harness prints scores with 17 fractional scientific digits.
Three frozen binaries were built against pinned siblings: base `61ccaed6`,
original optimization tip `c550bd94`, and review candidate `0b6a799d`. Only the
benchmark example was instrumented in the exported baseline snapshots.
At 256² on ladder image 1415, all 13 columns have identical f64 bits across all
three binaries in both compute and warm mode: 26 of 26 comparisons. This is a
measured finite input panel, separate from tolerance-based upstream parity.
[Full-precision rows](nn_opt2_2026-10-15/review_identity_scores.tsv),
[bit comparisons](nn_opt2_2026-10-15/review_bit_identity.tsv), and
[binary hashes](nn_opt2_2026-10-15/review_identity.json) retain the evidence.


### Final review correctness and memory

Production source `4841f218` restores the baseline zipped RGB row loop, applies
A-FINE's worker cap, counts actual PIL multiply-accumulates, leaves resize work
below 2,097,152 operations sequential, and handles empty axes. DreamSim returns
an error on an empty image. Unit controls compare exact output bits with one
and multiple workers for all six resize paths, center crop and all four planar
conversions; the parallel cases assert that helper threads actually launched.
The A-FINE cap-one control records zero helper launches in a fresh process.

The final frozen binary repeats all 26 exact score comparisons successfully:
[full-precision scores](nn_opt2_2026-10-15/review_final_identity_scores.tsv),
[bit comparisons](nn_opt2_2026-10-15/review_final_bit_identity.tsv),
[binary hashes](nn_opt2_2026-10-15/review_final_identity.json).
Debug and release NN tests, the pinned workspace fmt check, the CI Lint clippy
command, and RTen upstream parity for all 13 columns pass. Original model
files and golden tolerances are unchanged. Combined gate receipt:
`run-heavy: done rc=0 177s | peak-RSS 11.05GiB | min-avail 11433MiB | peak-load 28.45`.

Peak process RSS at 2048², RTen with 16 workers, was measured independently
with `/usr/bin/time -v` in adjacent baseline/fixed pairs, twice:

medians are lower in round a and higher in round b; the mean of the two
medians is 116.582 ms baseline versus 116.034 ms fixed. Warm at 1T is still
slightly higher in both rounds (77.8705 versus 78.4045 ms for the mean of

minima, in both rounds. Every baseline/fixed score in the timing panel is
bit-identical. These observations describe this host and measured panel.
