# nn-opt benchmark data — 2026-10-15, i265

CPU optimisation lane for `crates/zenmetrics-nn` (rten engine,
`RTEN_NUM_THREADS=16` unless noted). Harness:
`crates/zenmetrics-nn/examples/nn_bench.rs` —
`ZENMETRICS_NN_MODEL=<m> <bin> <models> <ladder> <out.tsv> 1415 <sizes> 3`,
models and ladder in `~/tmp/nn-phase0/`. Medians are of `n` pairs per
size; every landed change was also confirmed on two interleaved
old/new runs (`ab*_{old,new}_{a,b}.tsv`). Cross-session absolute drift
on this box is ~10% at 2048² — only same-session pairs compare.

TSV naming: `base_*` pre-lane, `v1` into_data outputs, `v2` fused DISTS
statistics, `v3` borrowed-input experiment (reverted, slower), `v4`
threaded metric heads, `abN_*` interleave N.

## Tried and dropped (numbers in TSVs)

- **v3, borrowed `NdTensorView` inputs + LPIPS input scratch**: −4 to −9%
  regression (v3_*, ab3_*). Owned inputs let rten run its leading
  in-place ops on the input buffer; a view forces an internal copy.
- **Shared 16-thread pool for `run_pair` vs the static 8+8 split**:
  +12% at 64² (task-stealing overhead), flat elsewhere — split stays.
- **Batch-2 single run**: impossible — trunk input dims are `[1,3,h,w]`
  with only h,w dynamic.
- **B-side head under the A trunk's tail**: no tail exists — pooled
  8/8 runs finish together.

## Parity

`dists 1.791e-7`, `lpips_squeeze 1.098e-7`, `lpips_alex`, `lpips_vgg`
below both; `warm_reference_equals_cold` passes.
